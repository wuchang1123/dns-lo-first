# Local First - 本地优先 DNS 服务器

基于 Go 开发的高性能 DNS 服务器，支持智能分流、病毒检测和定时更新。

- IPv4 Only，AAAA 查询转发，本服务不处理
- 终端里按 Ctrl+C 退出，停止 DNS 服务器

## 上游服务器

- 支持IP
- 支持DoH
- 实现上游服务器打分制
    - 最近响应延迟低的分值高
    - 按分值排序使用上游服务器
    - 分数相等的上游服务器随机提取
    - 1小时内有一次从分值最低的（不包括被冻结的）读取的机会
- 划分为本地和海外两大类
    - 各类按职能分流规则
    - 每一类服务器按打分制先提取一个 IP 使用
        - 超时，可并发尝试同类剩下的所有上游
        - 所有上游都超时视为失败
- 单个上游服务器超时时间
    - 3 秒，可通过配置修改
- 上游服务器超时处理
    - 冻结1分钟
    - 同类型全部冻结时先解冻最早冻结的上游

## 缓存

- 基础响应缓存：
    - 负责主要的 DNS 缓存
    - 采取乐观缓存：过期仍返回，ttl=3
        - 返回后仍然在后台执行后续逻辑（客户端该次查询算是已经结束，后面不需要再回复响应）
    - 缓存 key 按 qname + qtype + qclass
    - 每天定时清除早于 48 小时前创建的条目
    - 需要写上对应响应的上游服务器
- 校对结论缓存：
    - 保存域名的本地和海外响应信息
    - 保存对应上游服务器信息
    - 过期时间可配置
- 基础缓存+校对缓存：同时内存和文件存储，内存加速，文件持久化
    - 内存快速响应，文件人可读
- 基础缓存和校对缓存各个一套，相互不干扰

## 文件

- 配置文件 @config.yaml
- GFW域名 @data/common_blocked_domains.txt，有注释、空行
- ASN信息 @data/domain_asn.yaml 域名/组织/IP段映射信息

## 智能分流

- 默认所有域名使用本地和海外 DNS 上游服务器，并发查询
- 配置文件 local_domains 定义的域名只使用本地 DNS 上游服务器
- 配置文件 upstream.local_only 定义的域名只使用本地 DNS 服务器
- 配置文件 upstream.overseas_only 定义的域名只使用海外 DNS 上游服务器
- overseas_only > local_only > local_domains > default（默认并发）
    - apex + 子域
    - 支持 *.example.com 严格子域（RFC 4592）
- 所有地域名通过配置文件 local_domains.source_url 定时更新
    - 更新后可热加载

## ASN 检查
    - 配置文件有相应开关
    - ASN信息 domain_asn.yaml 域名/组织/IP段映射信息

## 校对比较
    - 结果一致的条件
        - IP 完全一样，或者其中有一个 IP 一样
        - 其中有 IP 在相同的 IP 段内：先校验"/24"，失败再校验"/16"


## 查询上游服务器的流程

1. 有基础缓存
    - 未过期，立即返回缓存的结果，本次查询结束
    - 已过期
        - 立即返回，ttl=3
        - 返回后如果不存在有相同查询的后台逻辑正在运行，那么仍然在后台执行后续逻辑
2. local_only、local_domains 的域名，只启用本地类上游服务器
    - 一有响应立即返回，同时更新基础缓存，本次查询结束
    - 6s超时
        - 响应统一处理：ttl=3
3. overseas_only 的域名，只启用海外类上游服务器
    - domain_asn.yaml 中有定义的域名
        - 对上游服务器的响应都进行简单的 ASN 污染识别
            - 通过污染识别的，立即返回响应，同时更新基础缓存，本次查询结束
            - 未通过污染识别的
                - 继续并发尝试同类剩下的所有上游，进行简单的 ASN 污染识别
                    - 一有通过污染识别的，立即返回响应，同时更新基础缓存
                - 剩下的所有上游也没有通过的时候，以最后一个上游服务器结果返回，并且打印 Warn 日志，禁止更新基础缓存
                    - ttl=30
    - domain_asn.yaml 中没有定义的域名
        - 一有响应立即返回，同时更新基础缓存，本次查询结束
    - 6s超时
        - 响应统一处理：ttl=3
5. 其他情况的域名
    - 并行查询本地、海外上游服务器
        - domain_asn.yaml 中有定义的域名
            - 对上游服务器的响应都进行简单的 ASN 污染识别
                - 通过污染识别的，立即返回响应，同时更新基础缓存，本次查询结束，后台继续运行后面逻辑
                - 未通过污染识别，且是来自海外类上游服务器的响应
                    - 继续并发尝试同类剩下的所有上游，进行简单的 ASN 污染识别
                        - 一有通过污染识别的，立即返回响应，同时更新基础缓存，后台继续运行后面逻辑
                    - 剩下的所有上游都没有通过的时候，以最后一个上游服务器结果返回，并且打印 Warn 日志，禁止更新基础缓存
                        - ttl=30
        - domain_asn.yaml 中没有定义的域名
            - 有校对结论缓存且未过期且校对结果一致的域名
                - 无论哪类上游服务器有响应时
                    - 立即返回响应，ttl=3
                    - 后台继续运行后面逻辑
            - 其他情况则等待海外上游服务器响应
                - 有响应立即返回响应，同时更新基础缓存
                - 后台继续运行后面逻辑
        - 都有返回的话，对结果做校对比较
            - 更新校对缓存
            - 取海外响应来更新基础缓存
        - 6s超时
            - 有海外响应结果，以该结果响应回客户端，并且记录基础响应缓存
            - 没有海外响应结果，以本地响应结果响应回客户端（若无则空）
            - 响应统一处理：ttl=3

## 日志系统

- 日志时间保留显示精确到ms
- 日志时间的年份只取最后两位

### 基础日志
    - 日志等级: debug, info, warn, error, fatal
    - 日志采用时区：Asia/Shanghai
    - 详细记录日志，有足够信息方便调试
    - 每天0点清除超过 48 小时的日志（启动时不要）

### 性能日志
    - 耗时统一ms单位，取小数点3位，四舍五入
    - 日志格式前面统一先显示时间、耗时
    - 耗时记录（独立文件记录 query.log）
        - 打印每个查询从进入到返回所需时间
            - 包含 qname/qtype/qclass、耗时、上游服务器、响应 IP 和 rcode
                - 耗时排在时间后面，域名前
                - 无错误不输出 rcode
                - 耗时格式
                    - 总耗时（本地上游服务器响应耗时若有 + 海外上游服务器响应耗时若有 + TLS 证书校验耗时）
            - 无键值格式输出
        - 打印每次上游查询起止的分段耗时
            - 最少包含上游服务器信息、开始&结束时间（HH:MM:SS.mmm）
        - 打印每次TSL校验起止的分段耗时
            - 最少包含域名、IP 信息、开始&结束时间（HH:MM:SS.mmm）
    - 每天0点清除超过 48 小时的日志（启动时不要）

## Bootstrap DNS

- 配置文件 bootstrap_dns，下载配置解析域名时使用的递归 DNS（Do53，host:port）
    - 本服务刚启动时系统 resolv 可能不可用（如指向 [::1]:53），此处显式指定可避免依赖本机解析
    - 留空则使用配置中的上游 DNS 服务器；若仍为空则内置 223.5.5.5 / 8.8.8.8 / 1.1.1.1。
